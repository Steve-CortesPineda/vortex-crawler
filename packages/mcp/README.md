# @stevecortesp/vortex-mcp

MCP server for [Vortex](https://github.com/Steve-CortesPineda/vortex-crawler): scrape, crawl, multi-engine search, autonomous research, tracking, and (optional) VANTA / macOS desktop tools.

**32 tools** in 0.2.0. The older 0.1.0 publish on npm advertised 18 tools.

```bash
npx @stevecortesp/vortex-mcp
```

Claude Code:

```json
{
  "mcpServers": {
    "vortex": {
      "type": "command",
      "command": "npx",
      "args": ["@stevecortesp/vortex-mcp"]
    }
  }
}
```

See the [repo README](https://github.com/Steve-CortesPineda/vortex-crawler#mcp-server-for-ai-agents) for the full tool table.
